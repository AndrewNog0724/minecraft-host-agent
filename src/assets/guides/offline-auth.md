# 离线与混合认证方案对比

玩家分正版（拥有 Mojang 账号）与离线（无正版账号）两类。服务端 `online-mode=false`
即关闭正版校验（俗称"离线模式"），任何人可用任意 ID 进入，因此：

- 建议开启白名单（whitelist + enforce-whitelist），只允许登记过的 ID 进入；
  纯局域网联机且无陌生设备接入时，服主可以评估后不开（mcha 支持跳过白名单）；
- 离线模式下任何人都可以冒用他人 ID，风险由服主承担，方案摘要中必须向玩家说明；
- 若服内同时有正版与离线玩家（混合场景），正版玩家用正版启动器直接进离线服时，
  其名字校验方式会变化，需要认证插件/mod 统一管理登录：
  - Paper 插件服：登录插件（如 LibreLogin / AuthMe 系）；
  - Fabric mod 服：EasyAuth mod。
- 混合方案下，正版玩家首次进入也需要按插件流程注册一次，这是正常现象。

常见坑：
1. 关了 online-mode 但忘了开白名单 → 服务器被陌生人进入；
2. 认证插件与某些 mod 冲突 → 优先选与生态兼容的认证方案；
3. 端口被占用导致"服务器开了但没人能进" → 先确认服务端日志出现 Done。
