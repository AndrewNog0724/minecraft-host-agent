# 内网穿透科普（为什么朋友连不上你的服务器）

家庭宽带大多没有公网 IP，朋友从外网无法直接访问你电脑上的端口。
解决办法从简单到复杂：

1. 同一局域网（同一个 WiFi/路由器）：直接用你的内网 IP 连接，什么都不用配；
2. 有公网 IP（宽带运营商标配或可申请）：路由器做端口映射（TCP/UDP 25565 →
   你的内网 IP），再放行系统防火墙；
3. 内网穿透（最常见）：由一台有公网 IP 的中转服务器把流量转发给你。
   - 樱花frp：国内节点多、延迟好、朋友零安装（只有服主跑客户端 frpc），
     免费流量包按签到/套餐获取；服主需注册 + 实名 + 获取访问密钥（一次性）；
   - 自建 frp：需要自己的 VPS，配置自由度高；
   - Tailscale：朋友也要装客户端，组成虚拟局域网。

本系统的编排策略：默认樱花frp（自动建隧道、托管 frpc、端到端验证），
有公网 IP 则给端口映射指引。
